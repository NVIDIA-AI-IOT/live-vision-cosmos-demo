# Security

## Report a vulnerability

Report suspected security vulnerabilities in Live Vision privately to the NVIDIA
Product Security Incident Response Team (PSIRT). Do not disclose vulnerability
details in GitHub issues, pull requests or discussions.

- Follow NVIDIA's [vulnerability reporting instructions](https://www.nvidia.com/en-us/security/report-vulnerability/), or
- Email [psirt@nvidia.com](mailto:psirt@nvidia.com), encrypting your report with
  [NVIDIA's public PGP key](https://www.nvidia.com/en-us/security/pgp-key/).

Include the repository name and affected commit or version, the type of issue,
steps to reproduce it, a proof of concept when available, and its potential impact.

See NVIDIA's [PSIRT policies](https://www.nvidia.com/en-us/security/psirt-policies/)
for coordinated disclosure information and the
[Product Security portal](https://www.nvidia.com/en-us/security/) for security bulletins.
